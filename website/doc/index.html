Documentation

The KZ Castor DSP is an advanced audio daemon and UI suite built in Rust, leveraging PipeWire for zero-latency audio manipulation. This guide explains how to deploy and configure the entire stack.

1. Installation

Ensure you have Rust, Cargo, and PipeWire installed on your Linux machine.

git clone https://github.com/brighteyekid/kz-dsp.git
cd kz-dsp
cargo build --release
cp target/release/iem-dspd ~/.cargo/bin/
cp target/release/iem-ui ~/.cargo/bin/

2. Running the Daemon

The DSP engine runs as a systemd background service. It will intercept your default PipeWire sink and apply the EQ and HRTF parameters natively before sending to hardware.

systemctl --user start iem-dspd
systemctl --user status iem-dspd

To view the control panel, run iem-ui in your terminal or application launcher.

3. Enabling Spatial Head Tracking

World-locked spatial audio requires the Python tracker module which uses OpenCV and MediaPipe Tasks API to estimate head yaw.

cd ~/Documents/kz
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 iem-tracker.py

Once running, your audio stage will physically lock to your room. To recenter the tracker, press c and Enter in the python terminal.
